│ TECHNICAL CHANGES REQUIRED                                                  │
└─────────────────────────────────────────────────────────────────────────────┘

Change #1: Cloudflare Environment Variables (5 mins per site)
────────────────────────────────────────────────────────────
  omnicms.pages.dev:   Add SITE_SLUG = "travel"
  omnicms1.pages.dev:  Add SITE_SLUG = "package"
  omnicms2.pages.dev:  Add SITE_SLUG = "design"
  
  Result: _seo-proxy.js converts /sitemap.xml → /{site}/sitemap.xml


Change #2: Backend getSiteUrl() Function (2 mins)
──────────────────────────────────────────────────
  OLD: Checks site.domains[0] OR req.headers.host
       → Always returns backend domain for Cloudflare requests
  
  NEW: Checks X-Forwarded-Host header FIRST (filters out backend)
       → Then falls back to site.domains[0]
       → Then falls back to FRONTEND_URL env var
       
  Result: Correct frontend domain in all sitemaps


Change #3: Frontend SEO Proxy (30 secs - optional)
───────────────────────────────────────────────────
  OLD: Only sets hostname query param if not already present
  
  NEW: Always sets hostname query param
  
  Result: Backend always knows which frontend is requesting
