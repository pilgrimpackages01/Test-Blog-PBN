🔴 THE PROBLEM
──────────────
Your 3 Cloudflare sites are returning sitemaps that point to the backend instead
of themselves. Google indexes the backend domain, not your frontends.

  omnicms.pages.dev/sitemap.xml     ❌ Returns: https://omnicms-backend.vercel.app/...
  omnicms1.pages.dev/sitemap.xml    ❌ Returns: https://omnicms-backend.vercel.app/...
  omnicms2.pages.dev/sitemap.xml    ❌ Returns: https://omnicms-backend.vercel.app/...

Result: All 3 sites appear as clones → Poor SEO, no differentiation


🟢 THE FIX (3 STEPS - 20 MINUTES)
─────────────────────────────────

STEP 1: Cloudflare Environment Variables (5 min per site)
  └─ Set SITE_SLUG env var:
     • omnicms.pages.dev:   SITE_SLUG = "travel"
     • omnicms1.pages.dev:  SITE_SLUG = "package"  
     • omnicms2.pages.dev:  SITE_SLUG = "design"
     └─ Re-deploy each project after adding

STEP 2: Backend Code Change (2 minutes)
  └─ Update function: getSiteUrl() in backend/server.ts (lines 226-235)
     └─ Copy from: FIXED_getSiteUrl.ts
     └─ Deploy to Vercel

STEP 3: (Optional) Frontend Code Change (30 seconds)
  └─ Update function: proxySeoRequest() in frontend/functions/_seo-proxy.js (line 16)
     └─ Remove "!targetUrl.searchParams.has('hostname')" check
     └─ Always set hostname param


✅ EXPECTED RESULTS
───────────────────

After 24-48 hours:

  omnicms.pages.dev/sitemap.xml     ✅ Returns: https://omnicms.pages.dev/travel/...
  omnicms1.pages.dev/sitemap.xml    ✅ Returns: https://omnicms1.pages.dev/package/...
  omnicms2.pages.dev/sitemap.xml    ✅ Returns: https://omnicms2.pages.dev/design/...

Result: Each site indexes independently, proper PBN structure


📋 WHAT CHANGED
───────────────

1. getSiteUrl() now checks X-Forwarded-Host header FIRST
   └─ Cloudflare sets this header automatically
   └─ Backend can now detect which frontend made the request

2. SITE_SLUG env var tells frontend to convert /sitemap.xml → /{site}/sitemap.xml
   └─ Without it, always serves global sitemap index

3. Result: Frontend domain appears in sitemaps, not backend domain
